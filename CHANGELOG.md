# Changelog

## 0.1.0 — 2026-10-30

- TypeScript/Electron desktop application for macOS arm64 and Windows x64.
- Local SQLite history, device profiles, direct conversations, fixed-member groups and local notes.
- UDP discovery, manual IPv4 connections, certificate-based TLS and durable offline outbox.
- Images, native attachments, clipboard paste, streaming file ranges, restart/resume and SHA-256 verification.
- Search, device inventory, transfer history, system notifications, tray and light/dark appearance.
- Native platform CI, application smoke tests and GitHub Releases with installers and checksums.
