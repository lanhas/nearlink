邻线的第一个版本：在附近，就相连。

为 Apple Silicon Mac 与 Windows x64 提供免登录的局域网聊天和文件传输。

- 文本、图片、文件；流式大文件传输、暂停、重启后续传与 SHA-256 校验。
- 自动发现和地址直连、私聊、固定成员群聊、个人资料、SQLite 本地历史及离线消息队列。
- 浅色/深色界面、图片预览、历史搜索、设备与传输面板、桌面通知、托盘常驻。
- 无云端、无遥测。设备之间使用证书标识与 TLS 加密，首次连接自动信任；适用于可信局域网。

选择适合自己系统的文件：macOS M 系列使用 DMG，Windows 使用 setup.exe；ZIP 和 portable.exe 为替代选项。下载后可对照 SHA256SUMS.txt 校验。

当前安装包没有 Apple Developer ID 公证或 Windows 商业签名，系统可能显示首次运行提示。请按仓库 README 中的说明打开，无需关闭安全保护。

已在自动化中覆盖多节点通信、离线重连、48 MB 文件的暂停/重启/续传和界面操作。实体设备及路由器之间的互通需要按实际网络验证。
